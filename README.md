# مدیریت نگین‌کاری — نسخه نهایی پروژه اندروید

امکانات:
- ثبت روزانه تاریخ، تعداد کار و توضیحات بدون نمایش قیمت در بخش کار
- ذخیره دائمی اطلاعات روی خود گوشی (آفلاین)
- سوابق و حذف رکوردهای کار
- بخش مالی جداگانه: طلب/کارکرد، نقدی/واریز، چک دریافتی و سررسید
- محاسبه خودکار مطالبات باقی‌مانده
- گزارش ماهانه بر اساس تاریخ شمسی
- PDF مخصوص ارائه به کارفرما شامل فقط تاریخ، تعداد، توضیحات و جمع کل
- امکان اشتراک PDF از داخل گوشی
- نام کارفرما و نام شما در PDF

## اجرا
پروژه را با Android Studio باز کنید. Android Studio در اولین Sync وابستگی‌ها را دریافت می‌کند.
حداقل Android 7 (API 24) و هدف API 35 است.

نکته: محیط ساخت این پروژه در این گفتگو Android SDK/Gradle کامل نداشت، بنابراین APK امضاشده ارائه نشده؛ فایل پروژه برای Build در Android Studio آماده است.
