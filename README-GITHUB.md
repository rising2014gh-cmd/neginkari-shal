# NeginKariManager — GitHub APK Build

این پروژه برای ساخت APK با GitHub Actions آماده شده است.

## ساخت APK
1. این پوشه را به عنوان یک Repository در GitHub آپلود کنید.
2. وارد تب **Actions** شوید.
3. Workflow با نام **Build Android APK** را انتخاب کنید.
4. روی **Run workflow** بزنید.
5. بعد از اتمام Build، در بخش **Artifacts** فایل `NeginKariManager-debug-apk` را دانلود کنید.

> این Workflow نسخه Debug و قابل نصب APK را می‌سازد.
